# Discovery Analytics website

Standalone React + Vite implementation of the six Figma pages.

## Run locally

```sh
npm install
npm run dev
```

## Pages

- `/` — Home
- `/about` — About
- `/services` — Services
- `/solutions` — Solutions
- `/careers` — Careers
- `/contact` — Contact

Original Figma assets are stored in `public/images/discovery/`.
